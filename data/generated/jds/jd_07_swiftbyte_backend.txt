About the Company:
SwiftByte Technologies powers the payment processing engines for e-commerce platforms across India. We process millions of transactions daily, demanding systems that are highly available, scalable, and secure. Our engineering teams thrive on solving complex concurrency and distributed systems problems. We value clean code, thorough testing, and robust software architecture.

You will write server-side code, design database schemas, and ensure our APIs are fast and reliable. You will work in an agile environment, participating in sprint planning, code reviews, and daily stand-ups.

* Develop robust REST APIs for web and mobile applications.
* Write complex SQL queries and optimize database performance.
* Implement authentication and authorization mechanisms for secure data access.
* Refactor legacy code to improve maintainability and performance.
* Write comprehensive unit and integration tests for all new features.
* Collaborate with frontend developers to define API contracts and integrate services.
