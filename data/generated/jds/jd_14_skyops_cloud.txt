Multiplayer game servers require immense scalability, ultra-low latency, and absolute reliability. We build the hidden infrastructure that keeps millions of gamers connected seamlessly. We are hiring a Cloud/DevOps Engineer to help manage and scale our massive global server fleets. You will spend your days configuring virtual machines, writing shell scripts, and ensuring our continuous integration systems are running flawlessly. You will learn how to design architectures that can survive massive traffic spikes during major game launches.

* Write shell scripts to automate repetitive system administration tasks.
* Manage source code repositories and configure automated build and test pipelines.
* Implement robust monitoring and alerting systems to detect server degradation.
* Perform regular security patching and system updates across server clusters.
* Respond to critical infrastructure alerts and document root cause analyses.
