About the Company:
TestMatrix Solutions is a specialized quality engineering firm partnering with e-commerce, edtech, and logistics companies to accelerate their release cycles. We build resilient end-to-end test suites that run across browsers, devices, and cloud environments. Our engineers are deeply involved in shift-left testing and continuous delivery practices.

Role Overview & Responsibilities:
We are hiring a QA/Test Automation Engineer to write, maintain, and scale automated browser and API test suites for our client platforms. You will work embedded inside agile product squads, catching regressions early and ensuring every code push meets strict reliability benchmarks.

* Write clean, maintainable end-to-end UI automation scripts for modern web applications.
* Build and execute automated REST API test collections to validate backend contracts.
* Reproduce, isolate, and log clear bug reports with screenshots, logs, and network traces.
* Integrate automated test suites into continuous integration pipelines for nightly runs.
* Review product specifications during sprint grooming to identify edge cases early.
* Track flaky tests and optimize test execution times across parallel runners.
