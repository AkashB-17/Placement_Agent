About the Company:
CodePeak Solutions builds sophisticated inventory and warehouse management software for large-scale e-commerce retailers. Our platforms handle thousands of concurrent inventory updates every second, ensuring that stock levels are perfectly synchronized across multiple storefronts. We pride ourselves on engineering excellence, relying on clean architecture and test-driven development to maintain our large codebases.

Role Overview & Responsibilities:
The Backend Engineer will focus on building high-performance server-side applications. You will be responsible for creating robust APIs, designing efficient database schemas, and writing business logic that drives our core inventory engine. You will be heavily involved in code reviews and architecture discussions.

* Design, develop, and maintain RESTful web services and microservices.
* Optimize database queries to ensure millisecond response times under heavy load.
* Implement secure authentication protocols for third-party API integrations.
* Write comprehensive unit tests and participate in peer code reviews.
* Troubleshoot production issues and resolve memory leaks or performance bottlenecks.
* Document system architecture and API endpoints for frontend consumers.
